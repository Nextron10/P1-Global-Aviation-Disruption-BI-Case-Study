# Phase 1 Remediation Change Log

Date: 24 September 2026  
Scope: raw-data reconciliation through PostgreSQL, SQL, technical documentation and architecture  
Deferred: Power BI semantic model, PBIX/PBIP content, DAX, report visuals, ERD and executive findings

This log preserves the material previous behavior and the reason for each correction. Git history remains the source for exact line-level changes; obsolete code is not retained as commented dead code.

## Version preservation

- The original tracked Python, SQL, README and editor files remain recoverable from the repository's Git history and can be compared line by line with the corrected working tree.
- Old executable code was not copied into large commented blocks. Doing so would leave two competing implementations in each file and create a poor portfolio review experience.
- The important previous behavior, evidence, correction and validation are recorded in this change log.
- The DOCX files were untracked when corrected. Their superseded claims are documented here, but separate byte-for-byte copies of those earlier DOCX files were not created.
- Raw source files, the Power BI project, the ERD, the dashboard screenshot PDF and the Executive Findings document were not modified in Phase 1.
