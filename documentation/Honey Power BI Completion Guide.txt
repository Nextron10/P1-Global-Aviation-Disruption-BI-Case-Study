GLOBAL AVIATION DISRUPTION ASSESSMENT 2026
POWER BI COMPLETION AND GITHUB HANDOFF GUIDE FOR HONEY

Purpose
=======

This guide starts after Step 1. Step 1 is already complete: the PostgreSQL data was refreshed in Power BI Desktop and the project was saved with Ctrl+S.

The project is a static, simulated portfolio case study. It is not a live aviation-monitoring product. Keep the existing four report pages and overall visual design. Correct the model, measures, filters, labels, and unsupported claims without rebuilding the complete dashboard.

Important safety rules
======================

1. Never enter a database password in Git, a text file, Power Query code, screenshots, documentation, or chat.
2. Enter the password only in the Power BI or PostgreSQL credential dialog on the local computer.
3. Keep Import storage mode. This project does not need DirectQuery.
4. Work on a new Git branch and commit in small checkpoints.
5. Do not delete the old compatibility views until every visual has been moved to the new sources and tested.
6. Do not combine detailed, modeled-summary, or modeled-estimate populations in one ratio.
7. Do not claim that conflict events caused disruption. The data supports descriptive comparison only.


STEP 2 - CLONE THE REPOSITORY AND CREATE A WORKING BRANCH
==========================================================

1. Install Git, PostgreSQL 18 or a compatible PostgreSQL version, Python, Visual Studio Code, and Power BI Desktop.
2. Clone the repository:

   git clone <REPOSITORY-URL>
   cd P1-Global-Aviation-Disruption-BI-Case-Study

3. Create a branch for the Power BI work:

   git switch -c powerbi-remediation

4. Confirm that these main folders exist:

   data
   documentation
   powerbi
   python
   sql
   visuals

5. Do not create or copy a .pbix file into the repository. Work from the .pbip project in the powerbi folder.


STEP 3 - PREPARE THE LOCAL PYTHON ENVIRONMENT
==============================================

1. Open the cloned repository folder in Visual Studio Code.
2. Open Terminal > New Terminal.
3. Create a local virtual environment:

   python -m venv .venv

4. Activate it in PowerShell:

   .\.venv\Scripts\Activate.ps1

   python -m pip install --upgrade pip

Execution notes
---------------

Detailed operational measures
-----------------------------

Detailed Cancellations =
COUNTROWS('aviation flight_cancellations')

Detailed Passengers Affected =
SUM('aviation flight_cancellations'[passengers_affected])

Detailed Reroutes =
COUNTROWS('aviation flight_reroutes')

Detailed Additional Distance Km =
SUM('aviation flight_reroutes'[additional_distance_km])

Detailed Extra Fuel Cost USD =
SUM('aviation flight_reroutes'[extra_fuel_cost_usd])

Detailed Reroute Delay Hours =
SUM('aviation flight_reroutes'[delay_hours])

Modeled summary measures
------------------------

Modeled Summary Airline Loss USD =
SUM('aviation vw_airline_loss_summary'[estimated_loss_usd])

Modeled Summary Cancellations =
SUM('aviation vw_airline_loss_summary'[cancellations_count])

Modeled Summary Reroutes =
SUM('aviation vw_airline_loss_summary'[reroutes_count])

Modeled Average Revenue Loss Pct =
AVERAGE('aviation vw_airline_loss_summary'[revenue_loss_pct])

Modeled estimate measures
-------------------------

Estimated Daily Loss USD =
SUM('aviation vw_airline_loss_estimate'[estimated_daily_loss_usd])

Estimated Cancellations =
SUM('aviation vw_airline_loss_estimate'[cancelled_flights])

Estimated Reroutes =
SUM('aviation vw_airline_loss_estimate'[rerouted_flights])

Estimated Fuel Cost USD =
SUM('aviation vw_airline_loss_estimate'[additional_fuel_cost_usd])

Estimated Passengers =
SUM('aviation vw_airline_loss_estimate'[passengers_impacted])

Estimated Cancellations per Estimated Reroute =
DIVIDE([Estimated Cancellations], [Estimated Reroutes])

Estimated Passengers per Estimated Reroute =
DIVIDE([Estimated Passengers], [Estimated Reroutes])

Estimated Fuel Cost per Estimated Reroute =
DIVIDE([Estimated Fuel Cost USD], [Estimated Reroutes])

Airport measures
----------------

Airport Flights Affected =

Airport Disruption Records =
COUNTROWS('aviation vw_airport_disruption')

Formatting rules
----------------

1. Format currency measures as USD with suitable display units.
2. Format counts as whole numbers with thousands separators.
3. Format distance and hours with suitable decimals.

5. Add descriptions to every measure. State the source table, population, and whether the value is detailed, modeled summary, or modeled estimate.


STEP 9 - REBUILD THE DATE DIMENSION
===================================

Replace the hard-coded DimDate expression with a date range derived from every dated fact table.

DimDate =
VAR AllDates =
    UNION(
        SELECTCOLUMNS('aviation flight_cancellations', "Date", 'aviation flight_cancellations'[date]),
        SELECTCOLUMNS('aviation flight_reroutes', "Date", 'aviation flight_reroutes'[date]),
        SELECTCOLUMNS('aviation vw_airport_disruption', "Date", 'aviation vw_airport_disruption'[date]),
        SELECTCOLUMNS('aviation conflict_events', "Date", 'aviation conflict_events'[date]),
        SELECTCOLUMNS('aviation vw_airspace_closure', "Date", DATEVALUE('aviation vw_airspace_closure'[closure_start_date])),
        SELECTCOLUMNS('aviation vw_airspace_closure', "Date", DATEVALUE('aviation vw_airspace_closure'[closure_end_date]))
    )
VAR StartDate = MINX(AllDates, [Date])
VAR EndDate = MAXX(AllDates, [Date])
RETURN
ADDCOLUMNS(
    CALENDAR(StartDate, EndDate),
    "Year", YEAR([Date]),
    "Month", FORMAT([Date], "MMMM"),
    "Month Number", MONTH([Date]),
    "Year Month", FORMAT([Date], "YYYY-MM"),
    "Quarter", "Q" & FORMAT([Date], "Q")
)

Then:

1. Sort Month by Month Number.
2. Select Table tools > Mark as date table > Date.
3. Confirm the expected range is 15 December 2025 to 17 June 2026.
4. Add these date-only calculated columns to the airspace table because the source fields contain timestamps:

   Closure Start Date =
   DATE(
       YEAR('aviation vw_airspace_closure'[closure_start_date]),
       MONTH('aviation vw_airspace_closure'[closure_start_date]),
       DAY('aviation vw_airspace_closure'[closure_start_date])
   )

   Closure End Date =

STEP 24 - FINAL GIT REVIEW AND COMMIT
=====================================

1. Run:

   git status --short
   git diff --stat

2. Review .gitignore before staging.
3. Stage named folders and files. Do not use git add . until ignored and temporary files have been checked.
4. Review staged files:

   git diff --cached --stat
   git diff --cached

   git diff -- data/raw
